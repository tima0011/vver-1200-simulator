# ATOMIC CORE — PROJECT MAP & ARCHITECTURE

## 1. Обзор проекта
**ATOMIC CORE** — интерактивное научно-образовательное веб-приложение (SPA) по ядерной инженерии, теплогидравлике и физике водо-водяных энергетических реакторов третьего поколения **ВВЭР-1200** (Gen III+).

---

## 2. Структура файлов проекта
```text
/
├── index.html            # Точка входа SPA, разметка SCADA-шапки с глобальным тумблером режимов
├── PROJECT_MAP.md        # Актуальная карта проекта, архитектурный манифест и статус разработки

```

## 3. Архитектура SPA и модули

### 3.1. Ядро приложения (`app.js`)
- Запуск роутера по событию `DOMContentLoaded`.
- Эмуляция телеметрических микрофлуктуаций мощности и давления в шапке (эффект живой SCADA).
- Глобальные шорткаты клавиатуры: `1` — Анатомия, `2` — Пульт оператора, `3` — Физика, `M` — переключение режима (SCADA / На пальцах).
- Управление глобальным тумблером режимов подачи информации: `[ SCADA Инженерия ]` / `[ Вся суть на пальцах ]`.

### 3.2. Хэш-роутер (`router.js`)
- Управляет маршрутизацией по хэшу URL (`#anatomy`, `#control`, `#physics`) без перезагрузки страницы.
- Обновляет `document.title`, подсвечивает активные вкладки навигации `nav-tab`.
- Рендерит целевой экран в контейнер `<main id="app-viewport">`.

### 3.3. Модель данных (`data.js`)
Содержит структурированные данные по 6 ключевым узлам реакторной установки ВВЭР-1200:
1. `core` — Реактор ВВЭР-1200 (Корпус и активная зона, 163 ТВС, 3200 МВт(т), 16.2 МПа).
2. `control-rods` — Стержни СУЗ и шаговые электромагнитные приводы (ШЭМ-М, 121 группа, время сброса ≤ 3.8 с).
3. `pressurizer` — Компенсатор давления 1-го контура (КД, 79 м³, паровая подушка, ТЭН 2520 кВт, 16.2 МПа).
4. `rcp` — Главный циркуляционный насос (ГЦНА-1391, подача 21 500 м³/ч, 7-тонный маховик выбега).
5. `steam-generator` — Горизонтальный парогенератор (ПГВ-1200, 11 000 трубок, пар 7.0 МПа).
6. `turbogenerator` — Быстроходный турбоагрегат (К-1200-6.9/50 + ТВВ-1200, 3000 об/мин, 1200 МВт(э)).

Каждый узел содержит:
- **Инженерные данные**: технологический код, параметры 1-го/2-го контуров, уставки защит, физические уравнения, сценарии аварийных отказов (LOCA, ATWS, кавитация).
- **Модуль «Суть на пальцах» (`simpleExplainer`)**:
  - `analogy`: бытовая аналогия из реальной жизни.
  - `simplePhysics`: физика простыми словами без формул.
  - `simpleFailure`: что случится при аварии и как спасает физика.
  - `simpleMetrics`: адаптированные наглядные показатели с подсказками.

### 3.4. Интерактивная 3D WebGL сцена и инспектор (`anatomy.js`)
- **3D-сцена энергоблока на Three.js (r128)**: WebGL-рендерер, PerspectiveCamera, OrbitControls (свободный облет, плавное демпфирование, зум, вращение).
- **Мягкое инженерное освещение и атмосфера**:
  - AmbientLight (глубокий синий фон реакторного зала).
  - Направленный ключевой и заполняющий свет (DirectionalLight).
  - Центральный точечный источник Cherenkov Radiation Glow (активная зона).
  - Пространственная инженерная сетка и фундамент гермооболочки.
- **Интерактивный контейнер `#reactor-3d-viewport`**:
  - Абсолютное позиционирование на всю левую рабочую область (`schematic-card`).
  - Адаптивная обработка ресайза окна через `ResizeObserver` и `window.resize`.
  - Плавающий оверлей HUD: кнопки управления камерой `[+]`, `[-]`, `[⟲] Сброс ракурса`, процентный бейдж.
  - Нижняя плашка быстрого выбора узлов ВВЭР-1200 (`nodes-switcher-strip`).
- **Инспектор узла (правая колонка)**:
  - Жестко зафиксированная ширина **440px** и высота **`calc(100vh - 84px)`**.
  - Плавный внутренний скроллбар (`scrollbar-width: thin; scrollbar-gutter: stable; scroll-behavior: smooth`).
  - **Двойной режим отображения данных**:
    - Инженерный вид (SCADA): уставки, уравнения деления ²³⁵U, прочность 15Х2НМФА-А, кризис теплообмена DNB, САОЗ, СПОТ.
    - Простой вид («На пальцах»): жизненные образы (скороварка, педаль тормоза, радиационный щит), доступная физика, пассивная безопасность.
  - Локальная кнопка переключения внизу описания карточки: `[ 💡 Объяснить этот узел на пальцах ]` / `[ ⚙️ Вернуть инженерный вид ]`.
  - Аварийный сброс СУЗ (АЗ-1) с реакцией световой телеметрии и гашением тепловой мощности.

                                     ├──► Wheel Dolly (minDistance 6, maxDistance 85)
